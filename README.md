# Stock-Market-Analysis-Dashboard


Professional interactive dashboard for comprehensive stock analysis with synthetic data generated using Python's random functions. Features 4 analysis modes (Technical, Fundamental, Advanced, Comparative) with trading simulation, 15+ real-time KPIs, and interactive visualizations. Built with Streamlit and Plotly, it demonstrates financial data analysis and interactive dashboard development skills. Perfect for educational purposes and investment analysis practice. Supports custom data uploads and real-time calculations
